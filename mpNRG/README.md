# MultipointNRG

Full-density-matrix NRG for local 2p, 3p and 4p partial spectral functions (Lee, Kugler & von Delft, PRX 11, 041007 (2021)). Work in progress; task sheet: [`docs/TASK.md`](docs/TASK.md), progress: [`STATUS.md`](STATUS.md).

Tests: `julia --project=mpNRG/test mpNRG/test/runtests.jl`.
